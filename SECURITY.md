# Security / 安全

## English

This is a source-only, draft-oriented workflow kit, not an Alibaba publishing service. Do not put account credentials, cookies, browser profiles, customer details, commercial datasets, or production captures in this repository or in issue reports.

For a suspected leak or security defect, use the repository's **Security → Report a vulnerability** option if enabled. Do not paste secrets into a public issue. Revoke an exposed credential at its provider first. Report a synthetic reproduction, affected version, and expected versus observed behavior.

Final publishing, RFQ submission, EDM sending, scheduling, and paid activation are outside this kit's execution authority. A valid local receipt is not live browser attestation. Unknown writes must remain blocked.

## 中文

这是只含源码、以草稿准备为目的的流程工具箱，不是阿里巴巴自动发布服务。不要把账号凭据、Cookie、浏览器资料、客户信息、商业数据或生产页面快照放入仓库或问题反馈中。

发现泄露或安全缺陷时，如仓库已启用，请使用 **Security → Report a vulnerability** 私密报告。不要在公开 issue 粘贴秘密；凭据泄露后先去服务提供方撤销。反馈应使用虚构复现数据，说明版本、预期行为和实际结果。

最终发布、RFQ 提交、EDM 发送、定时发送和付费开通均不在本工具箱执行权限内。本地回执通过不等于真实浏览器认证；未知写请求应保持阻断。
